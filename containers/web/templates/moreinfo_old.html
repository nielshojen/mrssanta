What is the Santa app?

The app is named Santa because it keeps track of apps that are naughty or nice.

We run Santa to make sure we only run software we know we can trust, so we can keep your and {{ response.organization }}'s data safe.

Apps we already know are allowed automatically.

Apps we don't know (and that are not deemed malicious) you can allow yourself:

Click Allow to approve the app.

If the security scan passes and the app is considered Safe:

You can then Allow the app to run on your own Mac. Macs sync rules about once every {{ response.sync_interval }} minute(s).

If you want to speed up this process, click the Santa icon in the menubar and click Sync.

If you did not intend to run this app, please Report as Malware.

If it's a Managed app (either one that requires approval or has a license cost), then the app is blocked until it's installed by the {{ response.selfserviceapp }} app.

If an app is approved on {{ response.vote_threshold }} unique Macs, then the rule will be converted to a global rule and the app will be allowed to run on all Macs.
